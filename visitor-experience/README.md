# 南风开窑记 · 本机旅行日记 H5

游客挑选照片或短片，写下当时的话，预览一篇连续滚动的旅行记，并在手机浏览器里生成可保存、可分享的 JPG 长图。

## 游客流程

1. 添加照片或 15 秒以内的短片，为每段写一句话，也可以自定义标题。
2. 预览整篇旅行记，返回后继续修改。
3. 作品和素材保存在当前手机浏览器的 IndexedDB 中，不上传到应用服务器。
4. 浏览器在本机合成旅行日记长图。支持图片文件分享的手机会打开系统分享面板；其他浏览器可以先保存长图，再从相册分享。

短片会以封面帧出现在长图里，原视频留在这部手机；需要分享视频时，请另外从相册分享原片。

## 本地预览

需要 Python 3.10+，无第三方依赖。项目根目录运行：

    python3 server.py --port 8787

浏览器访问 <http://127.0.0.1:8787>。此服务只提供静态文件，不接收游客照片，也不保存旅行记。正式手机体验可直接使用 HTTPS 静态托管页面。

## 点位入口

演示二维码地址可以把点位窑印预先带入创作流程：

- 古窑：`/?spot=kiln`
- 榕荫：`/?spot=banyan`
- 陶艺：`/?spot=craft`

## 本机数据与分享边界

- 作品及所选素材保存在当前浏览器和当前网站来源的本机 IndexedDB 中。其他手机、其他浏览器或其他网站来源无法打开这份本机作品。
- 分享内容是一张 JPG 长图，不是公开游记网页；收件人收到图片后可以查看或转发，但不能继续编辑。
- 作品列表和素材可能随浏览器站点数据清理而消失。生成后建议立即保存或分享长图。
- 系统不支持直接分享图片时，可在长图预览里点“保存长图”，再从手机相册发送。
- 景区示例图片只供体验预览；正式公开使用前要确认摄影者和授权范围。游客照片不会上传或进入示例页。
