# 南风开窑记 · 游客旅行记 H5

游客把南风古灶的照片、短片和当时的感受放进三个游览章节，预览成一篇明信片风格的长页，生成后即可分享链接。

## 游客流程

1. 在开始页了解成品形式，点击“开始记录”。
2. 为“遇见古窑 / 榕荫街巷 / 手上有陶”添加照片或 15 秒内短片，可为每段素材写一句描述，也可给整段旅程命名。
3. 在连续滚动的长页中预览标题、日期、章节图片与文字；返回后仍可修改。
4. 生成作品后得到独立链接。手机端优先调用系统分享；其他浏览器提供复制链接。游客也可保存一张明信片纪念图。

## 本地运行

需要 Python 3.10+，无第三方依赖：

    cd /path/to/nfc-project-demo/visitor-experience
    python3 server.py

浏览器访问 <http://127.0.0.1:8787>。本地原型支持照片/短视频上传、保存作品、刷新后通过随机链接重新打开、分享链接复制、下载纪念卡和创建者删除。

演示二维码地址可用以下链接生成二维码物料：

- 古窑：http://127.0.0.1:8787/?spot=kiln
- 榕荫：http://127.0.0.1:8787/?spot=banyan
- 陶艺：http://127.0.0.1:8787/?spot=craft

上述地址中的 127.0.0.1 只在运行服务的设备上有效，不能给游客作为公网二维码使用。

## 原型边界

- 作品和上传文件写入 `data/stories/`、`data/uploads/`，默认保留 30 天，到期后清理；上传者可从创建作品的浏览器删除。
- 分享链接只对持有链接的人可见，首期没有公开作品墙和评论。
- 服务只绑定本机回环地址；上传采用本地 JSON API 和文件系统，适合体验原型，不适合直接部署到公网。
- 正式上线前需换成有鉴权、速率限制、内容审核、私有对象存储和清理任务的后端，并复核告知、保存期限与现场点位二维码。
- 景区示例图片仅用于本地体验预览；正式公开使用前要确认摄影者和授权范围。游客上传内容不会自动进入示例页。

## 「窑格」互动游览

首页同时提供“先测测自己的窑格”入口，进入独立的窑格人格测试与景区任务体验。窑格采用静态 H5、本机 localStorage 与当前项目图片素材，无需更改开窑记作品流程。详见 [`yaoge/README.md`](./yaoge/README.md)。
