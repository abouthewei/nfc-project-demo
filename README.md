# nfc-project-demo

All independent static deployments are included:

- `Kobe/` — Kobe Bryant
- `Curry/` — Stephen Curry
- `Jordan/` — Michael Jordan
- `Babu-Art/` — Babu Art architectural heritage practice journal
- `UK-Sketches/` — Ye Gang's bilingual British travel sketchbook

Upload any directory as a static site, or open its `index.html` through a local HTTP server.
