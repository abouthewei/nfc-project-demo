# G-DRAGON Artist Archive

A responsive Korean / Chinese / English editorial page. First visit defaults to Korean; the selected language is saved in local storage, and the language buttons also set a shareable `?lang=ko|zh|en` URL.

## Preview locally

Open `index.html` directly or serve this directory using any static file server, for example:

```sh
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

See [MEDIA_SOURCES.md](MEDIA_SOURCES.md) for editorial scope, factual references, image credits, and licenses.
