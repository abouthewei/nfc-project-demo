# 南风古灶「古灶行当」H5

独立静态版手机 H5 入口，包含首页、答题、生成结果、职业结果和古灶行当卡分享。每个浏览器标签页的答题与结果只保存在当前页面内存中；刷新、关闭或重新打开都会回到首页，不读取或上传上一次的个人结果。

## 访问

GitHub Pages 部署后访问：

<https://abouthewei.github.io/nfc-project-demo/Yaoge-Visual-Refresh/>

此地址直接加载 H5 首页“开始入窑”，浏览器地址保持在本入口；页面代码仍由 yaoge/ 子目录提供。

## 本地预览

在本目录启动任意静态 HTTP 服务，例如：

~~~sh
python3 -m http.server 8000
~~~

打开 <http://127.0.0.1:8000/>。

## 目录

- yaoge/：页面、交互脚本、题目及职业原型内容。生成古灶行当卡时会在结果页上方打开独立弹窗。
- assets/yaoge/：南风古灶场景、12 种职业插画、六维图标和陶土纹理。
- assets/paper-grain.webp：页面纸张纹理。

古灶行当卡图片会动态绘制职业人物、“01 这很像你”关键词与完整描述、六维分数和做事倾向图。项目没有构建步骤，不需要后端；不同标签页拥有各自的页面内存状态。所有图片按目录相对路径加载。包内不包含机器本地运行数据、游客照片、缓存或开发截图。
