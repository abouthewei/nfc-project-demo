# 南风古灶「窑格」H5

窑格作为现有游客互动 H5 的独立入口，与“南风开窑记”共用项目中的静态技术栈和景区图片。它不依赖后端，可通过 `localStorage` 保存测试和游览进度。

## 本地运行

在 `visitor-experience/` 目录启动现有服务：

```sh
python3 server.py
```

打开 <http://127.0.0.1:8787/yaoge/>。也可以使用父目录已有静态服务直接访问该目录。

## 路由

路由保存在 hash 中，适合静态托管：`#/`、`#/test`、`#/result`。测试结果直接呈现职业原型、窑格维度和文化说明，并可在结果页内生成、下载或分享窑格卡；旧版任务、火点、开灶及独立分享路径会回到结果页（尚无结果时回到首页）。

开发页：`#/dev/personas`、`#/dev/questions`、`#/dev/missions`。

## 内容和实现

- `src/data.js`：六维、15 道题、职业原型、窑系和来源记录。
- `src/engine.js`：维度计分、隐藏职业原型及匹配。
- `src/journey.js`：本机测试结果、重测和本地埋点事件。
- `src/app.js`、`style.css`：H5 页面与交互。
- `src/adapters.js`：TimeWeave / TimeTag mock 接口。

窑格卡在当前设备浏览器中生成，不会上传。卡片素材采用景区龙窑背景、职业陶塑透明切图、窑系标志和六维彩色图标。
