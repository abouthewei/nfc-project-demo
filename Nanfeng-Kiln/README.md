# Nanfeng Kiln · Foshan

A responsive Chinese / English editorial guide to Nanfeng and Gao kilns, Shiwan ceramic craft, local customs, and a suggested visit through the heritage site.

## Preview locally

Open `index.html` directly or serve this directory with any static file server. The site uses relative paths and can be deployed as a self-contained directory.

See [sources.html](sources.html) for historical references, image credits, licenses, and the Bilibili video source.
