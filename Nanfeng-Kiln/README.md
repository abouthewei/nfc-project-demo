# 南风古灶 · Nanfeng Kiln

A responsive Chinese / English editorial guide to the Nanfeng and Gao dragon kilns, Shiwan ceramic craft, Lingnan customs, and a suggested visitor route.

The site follows three supplied visual references: a history spread with a kiln profile and timeline, a craft page with a six-stage process and Bilibili video, and a home page that leads from kiln traditions into a visitor route.

## Preview locally

Open `index.html`, or serve this directory with any static file server. All local assets use relative paths.
