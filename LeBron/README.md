# LeBron James static package

Open `index.html` from a static host. The package uses relative asset paths and can be placed in any subdirectory.

- Local source route: `http://127.0.0.1:5173/lebron`
- All ten featured moments use Bilibili's in-page player, with a direct source link below each player.
- Image credits and licenses are listed in `images/lebron/README.md`.
